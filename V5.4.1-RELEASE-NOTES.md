# FEDUSA Congress Management Platform v5.4.1

## Admin notification delivery fix

- Added explicit handling for Resend SDK error responses.
- Added a short delay before admin notifications to avoid rapid consecutive-send rate limits.
- Added retry and backoff handling for HTTP 429 and temporary Resend errors.
- Email failures now reach the Netlify function logs instead of being silently ignored.
- Delegate confirmation, multilingual templates, admin recipients and all v5.4 functionality remain unchanged.
