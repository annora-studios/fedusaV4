# FEDUSA Congress Management Platform v5.4.2

## Admin permanent deletion

- Added a red **Delete** action to each registration row in the admin portal.
- Requires two confirmations and the exact phrase `DELETE REGISTRATION`.
- Deletes the complete registration and every delegate linked to it.
- Deletes delegate headshots and badge QR assets.
- Removes delegates and registrations from their indexes.
- Removes stored congress and voting check-in data with the delegate records.
- Adds a permanent-deletion entry to the audit log.
- Existing **Cancel registration** functionality remains unchanged and is still recommended for genuine delegate withdrawals.
