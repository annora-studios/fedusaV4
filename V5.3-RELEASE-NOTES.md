# FEDUSA Congress Management Platform v5.3.2

## Multilingual registration

The delegate-facing registration page now supports:

- English (default)
- French
- Portuguese
- Spanish

The site detects the browser language on first visit, falls back to English, and remembers the delegate's manual selection in the browser. A language selector remains available in the page header.

## Multilingual email

The selected language is saved with the registration and used for:

- Initial registration confirmation emails
- Registration update confirmation emails
- Registration management-link emails

## Unchanged areas

The admin portal, check-in interface, reports, exports, badge printing, database field names and Android scanner remain in English.

## Technical notes

- New public translation engine: `public/i18n.js`
- New persisted registration field: `language`
- Supported values: `en`, `fr`, `pt`, `es`
- Unknown or missing values default to `en`

## v5.3.2 language update

Afrikaans was removed from the public language selector, browser detection, registration validation and delegate email templates. Browsers configured for Afrikaans now fall back to English.
